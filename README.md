# UGNAY-SUBAY · From Evidences to Results

An AI-assisted monitoring prototype for locally funded infrastructure in the Philippines (LGSF and 20% Development Fund projects). It links four evidence streams on each project (project records, independent validation, inter-agency monitoring and citizen feedback), lets review agents compare them with a mandatory red-team check, and leaves every decision to a person. It produces National and Regional Monitoring and Evaluation reports for management.

**Prototype.** Not an official DILG system. Includes project records, geotagged-photo counts, LIME-20 / RPMES monitoring data and TPM 2026 findings for FY 2022–2026.

Built for PP5538 AI for Public Policy, Lee Kuan Yew School of Public Policy, National University of Singapore.

## Run locally
Open `index.html` in Chrome or Edge. No server or installation needed.

## Views
- **DILG Central Office:** dashboard, National M&E Report (Word / PDF), quality checks, about
- **DILG Regional Office:** Regional M&E, project review with agents, citizen feedback inbox
- **Public:** project search, projects near you, citizen reports with geotagged photos
